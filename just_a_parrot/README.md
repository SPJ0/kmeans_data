# Just a Parrot™

A 2-minute vertical (1080×1920, 30 fps) comedy short for social media. It pokes fun at the "stochastic parrot" and "AI hit a wall" takes, and walks through what frontier models have actually done as of Sept 2026.

- **Video:** `just_a_parrot.mp4`
- **Caption and sources:** `CAPTION.md`

Everything in the video is generated by the code in `src/`:
- The animation is drawn with Cairo.
- The music and sound effects are synthesized with NumPy.
- The voices use the open-source Kokoro TTS.

## Rebuild

```bash
pip install numpy scipy pycairo soundfile kokoro-onnx   # plus ffmpeg on PATH
# Fonts (Google Fonts, OFL/Apache): Bangers, Luckiest Guy, Anton, Baloo 2, Space Mono -> ~/.local/share/fonts
# Kokoro model files -> $PARROT_ASSETS:
#   https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
#   https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
cd src && PARROT_ASSETS=/path/to/assets python3 main.py          # -> src/out/just_a_parrot.mp4
python3 main.py --stills 12,30,95                                 # preview frames only
```

To change lines, edit `src/script.py`. Scene timing follows the length of each voice line automatically.
